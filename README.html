ASHFALL

A two-player real-time cooperative survival escape for COMP4021. All game text, code comments and documentation are in English.

Start the single Node.js server

Use Node.js 22 or later. Open a terminal in the folder containing package.json, then run these commands in order:

npm install
node server.js

Open http://localhost:8000. No build step, external database or automated startup script is needed. The included assets work without external websites.

Connect both explorers

Use two different browsers or separate browser profiles, with a different account in each. Two regular tabs in the same profile share their login cookie. Create accounts, choose Find a teammate, agree on difficulty, then have both players choose Ready for expedition.

The objective

Charge A1 in level one, then A2 in level one's return area and B2 in level two. Enter level three to wake the destroyer in level one. Charge C3, follow the protected corridor to the relocated exit, then stand together in its ring for two seconds. You have 240 seconds; menus do not pause the clock.

Player kills drop stones. Walk within 1.5 tiles to collect them automatically. Each stone adds 25 altar energy or restores 40 mana. Unfinished altars decay; completed altars stay full. Both explorers down, timeout, or complete map destruction before C3 is full ends the run.

Cheat mode for marking

Press Tab during gameplay. Invincibility and infinite mana each have their own on/off switch and apply to both players in the room. Closing the panel preserves those effects. Restore and instant stage charge are one-time actions. Stage charge fills both A2 and B2 when appropriate, then opens the next stage through normal progression. Invincibility does not stop the clock or prevent world-collapse failure.

For a quick demonstration, enable invincibility, charge the first two stages, choose Teleport, jump both players to the C3 safe zone through the minimap, charge the final stage and enter the exit together. Cheated runs show statistics but cannot enter the official leaderboard. A new run resets all cheat effects and state.

Results and tests

Results show each player's score, kills, delivered stones, actual energy, revives and hits taken. The overall leaderboard retains each account's best clean victory per difficulty. Play again preserves the pair and returns to ready checks; return home leaves the room. A disconnect aborts a live run without ranking it.

npm run check
npm test

Tests use temporary data and an ephemeral local port. They cover rules, storage and real authenticated HTTP/WebSocket interactions. Complete the manual two-browser audio/visual checklist before the final video.

Lab basis and deliverables

See LAB_NOTES.md for adaptations from Lab 3 collision helpers, Lab 5 accounts and sessions, and Lab 6 Socket.IO pairing/readiness. The application has one Express/Socket.IO server and a Canvas renderer, with no game engine. The two included WAV sound effects are original generated assets.

DESIGN.md explains the full English design. COURSE_REQUIREMENTS.md maps requirements to the supplied handout, lists acceptance checks and records the required announcement, file and video submission formats. The final video must be one MP4 of at most five minutes.
